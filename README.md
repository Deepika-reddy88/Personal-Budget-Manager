# Personal Budget Manager

A Python-based desktop application for managing personal income and expenses using a graphical user interface.

## Features

- User registration and login
- Add income and expense transactions
- Categorize transactions
- Delete selected transactions
- Store transaction data using SQLite
- View transactions in a dashboard
- Generate expense distribution charts
- Display an overspending warning when expenses exceed income

## Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib
